# OpenMandriva Mailing Lists

OpenMandriva uses mailing lists for various communication channels. Here are the available lists:

## Development Lists

- **openmandriva-cooker@lists.openmandriva.org** - Main development discussion list for the Cooker (development) branch
- **openmandriva-dev@lists.openmandriva.org** - General development topics

## User Support Lists

- **openmandriva-user@lists.openmandriva.org** - For user support and questions

## Join a Mailing List

You can subscribe to mailing lists at: <https://www.openmandriva.org/lists>

## Unsubscribe

To unsubscribe from a mailing list, send an email to:

- `listname-unsubscribe@lists.openmandriva.org`

(Replace `listname` with the actual list name, e.g., `openmandriva-cooker-unsubscribe@lists.openmandriva.org`)

## Archives

Mailing list archives are available at the list information pages linked above.

## Etiquette

- Be respectful and constructive
- Keep discussions on-topic
- One message per topic (avoid top-posting)
- Use a clear, descriptive subject line

## Alternative Contact

For real-time communication, consider joining our Matrix chat rooms at [chat.en.html](/community/chat).
